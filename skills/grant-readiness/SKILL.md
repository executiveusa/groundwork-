# Grant readiness

1. Document set: determination letter, W-9, board list, budget, financials/990, policies, bios, logo pack, program one-pager. Mark have / need / not applicable.
2. Registrations: EIN, state registration, UEI + active SAM.gov (federal only), Grants.gov access, Candid profile.
3. Web proof: `/funders` summary, outcomes with method, governance page, transparent use of funds.
4. Funder fit: for each named target funder, check priorities, geography, award size, deadlines from the funder's own site. Use Grants.gov (no key) for federal. Treat any aggregator listing as a lead to verify, not a fact. Report negative results as "no match found in sources checked", not "no funding exists".
5. Never promise an award or tie our fee to one. Fees are fixed and may be listed as an allowable grant budget line only where the funder allows it.
