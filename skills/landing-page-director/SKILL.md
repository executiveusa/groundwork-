# Landing page director

Read `REFERENCE.md` (the owner's Landing Page Director workflow v1.0) and follow its state machine: LOCK, INSPECT, EVIDENCE, RESEARCH, CONVERSION, TERRITORIES, DESIGN LOCK, SPEC, BUILD, GAUNTLET, REPAIR, PROOF, RELEASE, LEARN.

Additions for this toolkit:
- Claims ledger: every claim on the page has a source or is removed. No invented logos, testimonials, counts or prices presented as facts.
- Anti-slop: no purple-gradient hero, no three identical icon cards, no filler headings, no stock people.
- Apply `research/collins-design-rules.md` for type, spacing, color, motion and mobile.
- Release gate: Lighthouse accessibility >= 95, no horizontal overflow at 320-430px, working form, contrast AA, reduced-motion fallback.
