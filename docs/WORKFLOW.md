# Engagement workflow

1. **Free footprint scan** (public info only): `scan` + `search` + `presence`. Output: a one-page summary the owner receives. Never published.
2. **Intake call** (grill mode in `skills/nonprofit-audit`).
3. **Full audit**: reasoning pass, browser review, report + roadmap, reviewed by a human before sending.
4. **Repair sprint**: P0/P1 fixes with proof (`skills/repair-sprint`). Wording gates: sponsor, board, counsel.
5. **Monthly care**: re-scan, stale content, listings, new checklist versions.
6. **Learn**: add new lessons to `kb/` with a precedent line.

Consent: full reports go only to the site owner on request. Sensitive findings (safeguarding, legal) are delivered privately.
